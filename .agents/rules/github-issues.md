# GitHub Issues & Milestone Tracking Directive

Always read and follow [`GITHUB_ISSUES_GUIDE.md`](file:///c:/Users/Bruger/OneDrive/Skrivebord/Code/busybiz/busybiz/GITHUB_ISSUES_GUIDE.md) before performing any code edits or feature development.

- Check for open GitHub issues matching the request.
- Create a GitHub issue if none exists.
- Assign the issue to an active Milestone.
- Log progress comments on the issue as criteria are met.
- Reference issue numbers in commits and close issues when complete.
- **Implementation Plan Suggestion**: Whenever asked to perform a coding task, suggest whether an implementation plan (`IMPLEMENTATION.md`) should be created first (noting that small/quick changes can skip creating a file if unnecessary).
